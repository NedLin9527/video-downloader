# 同步近期下載與桌面介面變更

## Why

提交 `f5f0267` 與 `b6421fb` 已調整播放清單下載和桌面介面，但尚未反映在 OpenSpec。此提案事後補齊追溯；桌面批次模式已完成視覺驗證。

## What Changes

- 記錄播放清單略過不可用項目、成功檔案及完成訊息的行為。
- 釐清單一媒體與播放清單的下載前磁碟空間檢查差異。
- 記錄 yt-dlp JavaScript runtime 探測及片段重試、續傳設定。
- 記錄桌面下載工作區、無主畫面捲動的版面目標，以及 FFmpeg 不可用時的按鈕狀態。

## Impact

涉及 Download Core、Desktop UI 和 Web UI/API 規格；不變更 API 欄位。差異已同步至基準規格；批次模式與最小視窗尺寸已完成視覺驗證。另已修正批次輸入提示，使其符合既有逗號分隔行為。
